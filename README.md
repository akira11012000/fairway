# ポケットコーチ

ゴルフのスコアとクラブ別飛距離を1つの画面で記録し、そのまま分析まで行うWebアプリです。
スマートフォンのブラウザだけで動きます。アプリのインストールもアカウント登録も不要です。

**公開URL** → https://akira11012000.github.io/fairway/index_2.html

> **⚠ 本アプリは開発中の試用版です。**
> モニターとしてご協力いただく方のみご利用ください。
> 記録が失われる可能性があります。ラウンド後は必ずバックアップを取ってください。

バージョン: v1.0（2026年9月1日時点）

## できること

### ラウンド中（1画面で完結）

上から順に、プレーの流れどおりに並んでいます。

| 順番 | 内容 |
|---|---|
| ① 飛距離計測 | GPSで実測。打数（1〜6打目）とクラブを選び、①開始 → 歩く → ②終了 → 保存 |
| ② ティーショット | 結果（キープ／左／右／バンカー／OB／池）と使用クラブ |
| ③ スコア入力 | スコアとパット数を数字キーパッド（1〜15）で直接入力 |
| ④ その他 | OB・バンカー・ペナルティの回数 |

- ホールタブ（1H〜18H）で任意のホールへ移動でき、入力済みのスコアが一覧で見えます
- スコアを入れると自動でパット数の欄に切り替わります
- パーオン・ボギーオン・FWキープは打数とパット数から自動判定します
- Par3ではティーショットの選択肢が「ワンオン／手前／奥／左／右…」に自動で切り替わります
- プレー日はカレンダーからいつでも変更できます（過去のラウンドの記録も可能）

### 飛距離計測

GPSによる2地点間の距離計測です。打った位置で①、ボール地点で②を押すだけで、
歩いている間も距離がリアルタイムに更新されます。

- 計測した距離は、入力中のホールと打数に自動で紐付きます
- 前のショットの着地点を次のショットの開始地点として引き継ぐ「続けて計測」に対応
- クラブごとに 実用平均・中央値・直近5球・最長・最短・ばらつき・**番手間の距離差** を集計
- 番手差が25y以上なら「距離の空白」、8y以下なら「番手の重複」を警告
- GPSが使えない環境向けに「残り距離から」「歩測」「座標貼り付け」「手入力」も用意

**精度について** — GPSの誤差は通常 ±5〜10m（約±6〜11ヤード）です。数ヤードの違いを
断定する道具ではなく、番手ごとのおおよその傾向をつかむためのものです。

### 分析

- 平均スコア／平均パット／FWキープ率／パーオン率／ボギーオン率／OB数
- スコアの推移、スコアの内訳（バーディ〜トリプル以上）
- Par別集計、ホール別成績（危険度判定つき）
- 数字に基づくコーチング所見と、次のラウンドの重点3項目

コースを2つ以上登録した場合、分析は**コース単位**で行われ、画面右上のプルダウンで切り替えます。
9ホール×2周のコースは、物理ホール1〜9に合算して集計します。

## ホーム画面に追加（アプリとして使う）

このアプリはPWA（インストールできるWebアプリ）です。ホーム画面に追加すると、
**専用アイコンで全画面起動し、圏外でも開けるようになります。**

- **iPhone（Safari）** … 共有ボタン →「ホーム画面に追加」
- **Android（Chrome）** … 右上の ︙ →「ホーム画面に追加」／「アプリをインストール」

ホーム画面から起動したアプリは、iOSの「7日間使わないとデータを削除する」仕組みの
対象外になります。**記録を守るため、必ず追加してください。**

## データについて

### 保存場所

入力したデータは **お使いの端末のブラウザ内** にのみ保存されます。

- GitHubには保存されません。このリポジトリにあるのはアプリ本体だけです
- 外部のサーバーにも送信されません。広告も、利用者の追跡もありません
- 他の人が同じURLを開いても、その人には何も表示されません
- 記録は**端末ごと・URLごとに別々**です。複数の端末では同期しません

### 通信量

**起動時以外、いっさい通信しません。** 外部のフォントや画像を読み込まないため、
ラウンド中の通信量はゼロです（GPSは衛星からの受信のみで通信を使いません）。
ホーム画面から起動する場合は端末内のキャッシュから開くため、起動時の通信も発生しません。

### バックアップと復元（重要）

**ラウンドが終わったら、必ずバックアップを取ってください。**

**作成**

1. 「データ」タブ →「**バックアップをコピー**」を押す
2. メモアプリ（iPhone）や Google Keep（Android）に貼り付けて保存

ファイルとして残す場合は「**バックアップ(JSON)**」を押します。
ファイル名は `pocketcoach_backup_YYYY-MM-DD.json`。Androidでは **Downloadフォルダ** に保存されます。

**復元**

- **ファイルから** … 「データ」タブ →「データの復元」→「ファイルを選択」→ JSONを選ぶ
- **コピーした文字から** … 「データの復元」の入力枠に貼り付けて「読み込む」

復元は「既存データに追加」です。今あるデータは消えません。同じラウンドが両方にある場合は、
新しく更新されたほうが残ります。

## 書き出し（CSV）

「データ」タブから2種類のCSVを書き出せます。ファイル名には日付が入ります。

### スコアCSV `pocketcoach_scores_YYYY-MM-DD.csv`

```
Round, Date, Course, Hole, Par, Score, Putts, FW_Attempt, FW_Hit,
ParOn, BogeyOn, OB, Bunker, Penalty, OneOn, TeeClub, TeeResult, Clubs, Note
```

- `Round`〜`Penalty`（A〜N列）は既存のExcel分析表（`aggregate_master`）と完全に同一
- `OneOn` 以降は追加列。既存の集計には影響しません
- `Clubs` は計測した実績から打順どおりに生成されます（例 `3W-7U-SW`）
- ラウンド番号（R01・R02…）は日付の古い順に自動で振り直されます

### 飛距離CSV `pocketcoach_distances_YYYY-MM-DD.csv`

```
Date, Time, Club, Yards, Meters, Accuracy_m, Course, Hole, ShotNo, Method
```

`Method` は計測方法（GPS ±6m ／ 残り距離 ／ 歩測 ／ 座標GPS ／ 手入力）です。

## 設定

「データ」タブから変更できます。

- **クラブセット** … 1本ずつ追加・削除・↑↓での並べ替え。「標準（アイアン中心）」「ウッド・UT中心」のひな型から一括で入れ替えることもできます。ここの並び順が、そのまま入力画面のボタンの並び順になります
- **コース** … Parをスペース区切りで入力して追加します。9ホールを2周する形式は「周回数」に 2 を指定します。初期登録は総武カントリー倶楽部 北コース（9ホール×2周／Par 70）
- **ラウンドの管理** … 日付の変更、ラウンドの削除（そのラウンドで計測した飛距離データも一緒に削除されます）

## 更新のしかた

1. 新しい `index_2.html` を用意する
2. このリポジトリで **Add file → Upload files**
3. ファイルをドラッグして **Commit changes**

**同じファイル名なので上書きされ、URLは変わりません。**
画面本体はネットワーク優先で読み込むため、**次に開いたときに自動で新しい版になります。**
保存済みのデータはアプリを更新しても消えません。

`sw.js` を変更した場合は、そちらも同じ手順で上書きしてください。

## 技術メモ

- アプリ本体は単一のHTMLファイル。外部ライブラリ・外部フォント・画像を一切読み込みません
- PWA対応（manifest + サービスワーカー）。画面本体はネットワーク優先、アイコン類はキャッシュ優先
- 位置情報は Geolocation API（`watchPosition`）。2地点間の距離は Haversine 式で算出
- データは `localStorage` に保存。ブラウザ内で完結します
- グラフはインラインSVGで描画（ライブラリ不使用）
- ライトモード／ダークモードの両方に対応

### GPSについての注意

このアプリは **単独のページとして開いた場合のみGPSが使えます。**
他のページの中に埋め込まれた（iframe内の）状態では、ブラウザの仕様により
位置情報が許可されません。必ず上記の公開URLから直接開いてください。

### 競技での使用について

ゴルフ規則4.3により、**競技における距離計測機器の使用は、委員会がローカルルールで
認めた場合に限られます。** また、認められる場合でも計測できるのは距離のみで、
高低差の補正・風速・気温などの機能は禁止されています。

本アプリはプレー後の記録を目的としたもので、次打の距離を示す道具ではありませんが、
競技やコンペでご使用になる場合は、**必ず主催者・競技委員会にご確認ください。**
