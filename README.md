# ポケットコーチ

ゴルフのスコアとクラブ別飛距離を記録し、そのまま分析まで行うWebアプリです。
スマートフォンのブラウザだけで動きます。アプリのインストールもアカウント登録も不要です。

**公開URL** → https://akira11012000.github.io/fairway/index_2.html

> **⚠ 本アプリは開発中の試用版です。**
> モニターとしてご協力いただく方のみご利用ください。
> 記録が失われる可能性があります。ラウンド後は必ずバックアップを取ってください。

バージョン: v1.2（2026年9月2日）

## スコア入力

ホールのプレーが終わってから、上から順に入力していきます。

1. **スコア** … 自分のスコアとパット数を数字キーパッド（1〜15）で入力
2. **同伴競技者** … 名前を登録した方のスコアを入力
3. **ティーショット** … 方向（フェアウェイキープ／左／右／手前）と使用クラブ
4. **OB・バンカー・ペナルティ** … 回数を＋−で入力
5. **オリンピック** … 実施している場合、各プレーヤーの点数

### 入力欄が自動で移動します

数字を押すたびに **自分のスコア → PUTT → 同伴者1 → 同伴者2 → 同伴者3** と自動で移ります。
「5・2・6・4・7」と続けて押すだけで4人分が入ります。戻りたいときはその枠を直接押してください。

### 自動で判定される項目

- **パーオン／ボギーオン** … 打数とパット数から自動計算
- **FWキープ** … Par4・Par5で「フェアウェイキープ」を選んだ場合
- **ワンオン** … Par3で「ワンオン」を選んだ場合（Par3は選択肢が自動で切り替わります）

### ホールの移動

画面上部のホールタブ（1H〜18H）で、どのホールにも直接移動できます。
入力済みのホールにはスコアが表示されます。

## 飛距離計測

GPSで2地点間の距離を計測します。打った位置で①、ボール地点で②を押すだけで、
歩いている間も距離がリアルタイムに更新されます。

1. 記録するホールと打数（1〜6打目）、クラブを選ぶ
2. **① この位置から計測開始**
3. 打って、ボールの位置まで歩く
4. **② ボール地点で計測終了** → 距離を確認して保存

保存すると自動で次の打数に進み、**「▶ ここから続けて計測」** が表示されます。
前のショットの着地点をそのまま次の開始地点として使うので、測位を待つ必要がありません。

### 集計される内容

クラブごとに、実用平均・中央値・直近5球・最長・最短・ばらつき・**番手間の距離差** を集計します。
番手差が25y以上あれば「距離の空白」、8y以下なら「番手の重複」を警告します。

### GPSが使えないとき

「残り距離から」「歩測」「座標を貼り付け（ショートカット）」「手入力」の4つの方式を用意しています。

**精度について** — GPSの誤差は通常 ±5〜10m（約±6〜11ヤード）です。数ヤードの違いを
断定する道具ではなく、番手ごとのおおよその傾向をつかむためのものです。

## 合計

18ホールの入力が終わると、「合計」タブで次の内容を確認できます。

- **スコアカード** … 1〜18ホールを横に並べ、全プレーヤーのスコアとOUT／IN／合計を表示。バーディ以下は青、ダブルボギー以上は赤
- **自分のまとめ** … スコア・パット・FWキープ率・OB／ペナルティ回数
- **オリンピック** … 各ホールの点数、合計点、収支、**誰が誰にいくら払うか**
- **ラウンドを終了する** … 終了後も「編集を再開する」で戻せます

上部のプルダウンで過去のラウンドも見返せます。

### オリンピックの精算方法

**総当たり方式**で計算します。各プレーヤーと1対1で点差×レートをやり取りする形式です。

> 例：自分18点・田中18点・鈴木18点・佐藤12点（1点＝100円）
> → 佐藤さんが3人にそれぞれ¥600ずつ支払い（合計 −¥1,800）

レートはラウンド開始時、または「データ」タブで設定できます（初期値100円）。

## 分析

コースごとに集計します。2つ以上のコースを記録している場合は、画面右上のプルダウンで切り替えます。
9ホール×2周のコースは、物理ホール1〜9に合算して集計します。

### 目標設定

「データ」タブで3段階から選びます。選んだ目標に応じて、**目標値・達成の色分け・コーチング所見の内容**が変わります。

| 指標 | 100切り | 90切り | 80切り |
|---|---|---|---|
| 平均スコア | 100未満 | 90未満 | 80未満 |
| FWキープ率 | 40%以上 | 55%以上 | 65%以上 |
| パーオン率 | 10%以上 | 20%以上 | 40%以上 |
| ボギーオン率 | 55%以上 | 70%以上 | 85%以上 |
| 平均パット | 36以下 | 33以下 | 30以下 |
| OB | 2回以下 | 1回以下 | 0.5回以下 |

### 表示される内容

- KPI6指標（目標に対する達成度をバーで表示）
- スコアの推移、スコアの内訳（バーディ〜トリプル以上）
- Par別集計、ホール別成績（危険度判定つき）
- 強み・改善点のトップ3、数字に基づく所見、次のラウンドの重点3つ

## データについて

### 保存場所

入力したデータは **お使いの端末のブラウザ内** にのみ保存されます。

- GitHubには保存されません。このリポジトリにあるのはアプリ本体だけです
- 外部のサーバーにも送信されません。広告も、利用者の追跡もありません
- 他の人が同じURLを開いても、その人には何も表示されません
- 記録は**端末ごと・URLごとに別々**です。複数の端末では同期しません

### 通信量

**起動時以外、いっさい通信しません。** 外部のフォントや画像を読み込まないため、
ラウンド中の通信量はゼロです（GPSは衛星からの受信のみで通信を使いません）。
ホーム画面から起動する場合は端末内のキャッシュから開くため、起動時の通信も発生しません。

### バックアップと復元（重要）

**ラウンドが終わったら、必ずバックアップを取ってください。**

**作成**

1. 「データ」タブ →「**バックアップをコピー**」
2. メモアプリ（iPhone）や Google Keep（Android）に貼り付けて保存

ファイルとして残す場合は「**バックアップ(JSON)**」を押します。
ファイル名は `pocketcoach_backup_YYYY-MM-DD.json`。Androidでは **Downloadフォルダ** に保存されます。

**復元**

- **ファイルから** … 「データの復元」→「ファイルを選択」→ JSONを選ぶ（選んだ瞬間に復元）
- **コピーした文字から** … 入力枠に貼り付けて「読み込む」

復元は「既存データに追加」です。今あるデータは消えません。同じラウンドが両方にある場合は、
新しく更新されたほうが残ります。

## 書き出し（CSV）

「データ」タブから2種類のCSVを書き出せます。ファイル名には日付が入ります。

### スコアCSV `pocketcoach_scores_YYYY-MM-DD.csv`

```
Round, Date, Course, Hole, Par, Score, Putts, FW_Attempt, FW_Hit,
ParOn, BogeyOn, OB, Bunker, Penalty, OneOn, TeeClub, TeeResult, Clubs, Note
```

- `Round`〜`Penalty`（A〜N列）は既存のExcel分析表（`aggregate_master`）と完全に同一
- `OneOn` 以降は追加列。既存の集計には影響しません
- `Clubs` は計測した実績から打順どおりに生成されます（例 `3W-7U-SW`）
- ラウンド番号（R01・R02…）は日付の古い順に自動で振り直されます

### 飛距離CSV `pocketcoach_distances_YYYY-MM-DD.csv`

```
Date, Time, Club, Yards, Meters, Accuracy_m, Course, Hole, ShotNo, Method
```

## 設定（データタブ）

- **目標設定** … 100切り／90切り／80切りから選択
- **オリンピック** … 1点あたりの金額
- **クラブセット** … 追加・削除・↑↓での並べ替え。「標準（アイアン中心）」「ウッド・UT中心」のひな型から一括入れ替えも可能。ここの並び順が入力画面のボタンの並び順になります
- **コース** … Parをスペース区切りで入力して追加。9ホールを2周する形式は「周回数」に 2 を指定。初期登録は総武カントリー倶楽部 北コース（9ホール×2周／Par 70）
- **ラウンドの管理** … 日付の変更、ラウンドの削除（そのラウンドの飛距離データも同時に削除）

## ホーム画面に追加（アプリとして使う）

このアプリはPWA（インストールできるWebアプリ）です。ホーム画面に追加すると、
**専用アイコンで全画面起動し、圏外でも開けるようになります。**

- **iPhone（Safari）** … 共有ボタン →「ホーム画面に追加」
- **Android（Chrome）** … 右上の ︙ →「ホーム画面に追加」／「アプリをインストール」

ホーム画面から起動したアプリは、iOSの「7日間使わないとデータを削除する」仕組みの
対象外になります。**記録を守るため、必ず追加してください。**

## 技術メモ

- アプリ本体は単一のHTMLファイル。外部ライブラリ・外部フォント・画像を一切読み込みません
- PWA対応（manifest + サービスワーカー）。画面本体はネットワーク優先、アイコン類はキャッシュ優先
- 位置情報は Geolocation API（`watchPosition`）。2地点間の距離は Haversine 式で算出
- データは `localStorage` に保存。ブラウザ内で完結します
- グラフはインラインSVGで描画（ライブラリ不使用）
- 画面の更新は変更部分のみを書き換える方式。入力中にスクロール位置が動きません
- iPhone SE（320px）〜Pro Max（428px）で横方向のはみ出しがないことを確認済み
- ライトモード／ダークモードの両方に対応

### GPSについての注意

このアプリは **単独のページとして開いた場合のみGPSが使えます。**
他のページの中に埋め込まれた（iframe内の）状態では、ブラウザの仕様により
位置情報が許可されません。必ず上記の公開URLから直接開いてください。
