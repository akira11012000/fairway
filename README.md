# ポケットコーチ

ゴルフのスコアとクラブ別飛距離を記録し、そのまま分析まで行うWebアプリです。
スマートフォンのブラウザだけで動きます。アプリのインストールもアカウント登録も不要です。

**公開URL** → https://akira11012000.github.io/fairway/index_2.html

> **⚠ 本アプリは開発中の試用版です。**
> モニターとしてご協力いただく方のみご利用ください。
> 記録が失われる可能性があります。ラウンド後は必ずバックアップを取ってください。

バージョン: v1.5（2026年9月10日）

---

## 画面の構成

| タブ | 役割 |
|---|---|
| **ホーム** | これまでの成績のまとめ、最近のラウンド、クラブ別の実測平均 |
| **スコア入力** | ホールごとのスコア・パット・ティーショット・OB等の記録 |
| **飛距離計測** | GPSによるクラブ別飛距離の計測と、クラブ別の集計 |
| **合計** | 全プレーヤーのスコアカード、オリンピックの集計 |
| **分析** | 目標に対する達成度、9ホール別・ホール別成績、コーチング所見 |
| **データ** | CSV書き出し、バックアップ、使用容量、目標・クラブ・コース設定 |

画面下のタブバーはアイコン付きで、いまどこにいるか一目で分かります。
ライトモード／ダークモードの両方に対応しています。

## スコア入力

### ラウンドを始める

「スコア入力」タブで、**プレー日 → コース →（27ホールのコースなら回る9ホール）→ 同伴競技者の名前 → オリンピックの有無** を選んで開始します。

日付を変えれば、**過去にプレーしたラウンドを後からまとめて入力**することもできます。

### ホールごとの入力

ホールのプレーが終わってから、上から順に入力していきます。

1. **スコア** … 自分のスコアとパット数をキーパッドで入力
2. **同伴競技者** … 名前を登録した方のスコアを入力
3. **ティーショットのクラブ** … 13本を2行に並べたボタンから選択
4. **ティーショットの方向** … キープ／左／右／手前（Par3はワンオン／手前／奥／左／右）
5. **OB・バンカー・ペナルティ** … 回数を＋−で入力
6. **オリンピック** … 実施している場合、各プレーヤーの点数

### キーパッドは 0〜9 と「10＋」の2行

数字は **0〜9 の10個と「10＋」「消す」** の2行に収めています。

10以上を入れるときは **「10＋」を押してから数字**を押します。押すと数字の表示が
**10・11・12・13・14・15** に切り替わるので、頭の中で足し算する必要はありません。
数字を入れると「10＋」は自動で解除されます（上限は15）。

### 入力欄が自動で移動します

数字を押すたびに **自分のスコア → PUTT → 同伴者1 → 同伴者2 → 同伴者3** と自動で移ります。
「5・2・6・4・7」と続けて押すだけで4人分が入ります。戻りたいときはその枠を直接押してください。

### 自動で判定される項目

- **パーオン／ボギーオン** … 打数とパット数から自動計算
- **FWキープ** … Par4・Par5で「キープ」を選んだ場合
- **ワンオン** … Par3で「ワンオン」を選んだ場合（Par3は選択肢が自動で切り替わります）

### ホールの移動

画面上部のホールタブで、どのホールにも直接移動できます。
タブは上段が **ホール番号（1H・2H…／27ホールのコースは 東1H・中1H…）**、
下段が **入力前は PAR、入力後は赤いスコア** です。どこまで入れたか一目で分かります。

## 飛距離計測

GPSで2地点間の距離を計測します。打つ位置で①、ボール地点で②を押すだけです。

1. **記録するホール**と**何打目**を確認（− ＋ で変更できます）
2. クラブを選ぶ
3. **① 打つ位置でタップ** … 誤差の表示が出るのを2〜3秒待ってから打ってください
4. 打って、ボールの位置まで歩く（**画面を消してポケットに入れて構いません**）
5. **② ボール地点で確定** … 数秒で距離が確定します
6. **「この記録を保存する」（緑）** または **「破棄する」（赤）** を選ぶ

ヤーデージは待機中・計測中・確定後のどの場面でも **画面の同じ位置に大きく**表示されます。

### 記録するホールと何打目

「記録するホール」は **スコア入力で選んでいるホールがそのまま表示されます。**
− ＋ で前後のホールへ移動できます。

「何打目」は、飛距離計測タブを開いた時点で **1打目**から始まります。− ＋ で 1〜9打目まで変更でき、
記録を保存すると自動で次の打数に進みます。

### もとに戻す

①②の右隣に **「↩ もとに戻す」** ボタンがあります。押し間違えても戻せます。

| 押した場面 | 動作 |
|---|---|
| ②の画面（①を押し間違えた） | 計測をやめて待機に戻ります |
| 確定画面（②を押し間違えた） | 開始地点をそのままに計測へ戻ります |
| ①の画面（保存を押し間違えた） | 直前に保存した記録を取り消します（打数も1つ戻ります） |

保存と破棄はどちらかを選ぶまで次に進めないので、うっかり記録を取りこぼすことはありません。

### 画面を消しても大丈夫です

①を押したあと画面を消してポケットに入れ、ボール地点で画面をつけて②を押す、という使い方ができます。

- 画面をつけた瞬間に測位を自動で張り直します
- **画面を消す前の古い位置は使いません。** 戻ってから測り直した位置だけを使います
- ②を押したときにまだ測れていなければ、ボタンが「測位中… 自動で確定」に変わり、
  測位できた瞬間に自動で確定します（押し直す必要はありません）
- 計測の途中でアプリが終了しても、開始地点は端末に保存されています。
  開き直すと飛距離計測の画面から続けられます（3時間で自動失効）

スコア入力タブに移動して戻ってきても、計測は続いています。

### 測位誤差の警告

| 誤差 | 表示 |
|---|---|
| ±10m以下 | 緑「計測できます」 |
| ±11〜25m | オレンジ「⚠ 測位誤差が大きめです。飛距離が10〜20yずれることがあります」 |
| ±26m以上 | 赤「⚠ 測位誤差が大きすぎます。この状態では正しく計測できません」 |

待機中・計測中・保存確認の3か所すべてに表示されます。
測位に10秒以上かかっている場合は、対処法も案内します。

### 反応を速くする設定

「ラウンド中はGPSを温めておく」（初期状態オン）にしておくと、ラウンド中ずっと測位を続けるため、
**①を押した瞬間に開始地点が決まります。** 電池を節約したい場合はオフにできます（①の反応が数秒遅くなります）。

### 精度についての注意

表示される誤差は **その瞬間の「絶対位置」の誤差**であって、飛距離の誤差ではありません。
2地点の差を測るため、電離層などによる共通のズレは引き算でほぼ相殺されます。

それでも1球ごとの数字にはばらつきがあります。**1球の数字ではなく、10球20球と貯めた平均**を
見てください。球数が増えるほどばらつきは小さくなります。

**精度を上げるコツ**

- 機内モードにしない（このアプリはラウンド中いっさい通信しないので、機内モードは不要です）
- 計測タブを開いてから10〜20秒待ち、誤差が下がってから①を押す
- ①②を押す瞬間だけは手に持ち、空が見える状態で
- ①と②を同じような環境（両方とも開けた場所）で押す
- 木の下・カートのそば・建物の陰・法面の下を避ける

### 集計される内容

クラブごとに、実用平均・中央値・直近5球・最長・最短・ばらつき・**番手間の距離差** を集計します。
番手差が25y以上あれば「距離の空白」、8y以下なら「番手の重複」を警告します。
実用平均は外れ値（IQR法）を除いた平均なので、大きく外れた1球で平均が壊れることはありません。

### GPSが使えないとき

「予備：残り距離から」「予備：歩測」「座標を貼り付け」「手入力」を用意しています。

## 27ホールのコース（東・中・西）

総武コースのように9ホール×3の27ホール構成に対応しています。

- ラウンド開始画面で、**回る9ホールをタップした順に選びます**（東→中、中→西、西→東 など自由）
- 3つすべて選べば27ホールのラウンドになります
- ホール番号は **東1H・東2H … 中1H … 西9H** と表示されます
- 合計タブの集計欄は OUT／IN ではなく **東計・中計・西計・合計** になります

## 合計

18ホール（または27ホール）の入力が終わると、「合計」タブで次の内容を確認できます。

- **スコアカード** … 全ホールを横に並べ、全プレーヤーのスコアと区間計・合計を表示。バーディ以下は青、ダブルボギー以上は赤
- **自分のまとめ** … スコア・パット・FWキープ率・OB／ペナルティ回数
- **オリンピック** … 各ホールの点数、合計点、収支（ポイント）
- **ラウンドを終了する** … 終了後も「編集を再開する」で戻せます

上部のプルダウンで過去のラウンドも見返せます。

### オリンピックの集計

**総当たり方式のポイント計算**です。各プレーヤーとの点差の合計が「収支」になります。
全員の収支を足すと必ず 0 になります。金額の計算は行いません。

> 例：自分18点・田中18点・鈴木18点・佐藤12点
> → 佐藤さんは −18点、他の3人は各 +6点

## 分析

コースごとに集計します。2つ以上のコースを記録している場合は、画面右上のプルダウンで切り替えます。
9ホール×2周のコースは、物理ホール1〜9に合算して集計します。

### 目標設定

「データ」タブで3段階から選びます。選んだ目標に応じて、**目標値・達成の色分け・コーチング所見の内容**が変わります。

| 指標 | 100切り | 90切り | 80切り |
|---|---|---|---|
| 平均スコア | 100未満 | 90未満 | 80未満 |
| FWキープ率 | 40%以上 | 55%以上 | 65%以上 |
| パーオン率 | 10%以上 | 20%以上 | 40%以上 |
| ボギーオン率 | 55%以上 | 70%以上 | 85%以上 |
| 平均パット | 36以下 | 33以下 | 30以下 |
| OB | 2回以下 | 1回以下 | 0.5回以下 |

### 表示される内容

- KPI（ラウンド数・平均スコア・平均パット・FWキープ率・パーオン率・ボギーオン率・OB）
- スコアの推移、スコアの内訳（バーディ〜トリプル以上）
- Par別集計
- **9ホール別の成績**（27ホールのコースのみ）… 東・中・西それぞれの9ホールあたりの平均打数・vs Par・平均パット・FW率・パーオン率・OB
- **ホール別成績**（危険度判定つき）… 27ホールのコースでは **すべて／東／中／西** で絞り込めます
- 強み・改善点のトップ3、数字に基づく所見、次のラウンドの重点3つ

## データについて

### 保存場所

入力したデータは **お使いの端末のブラウザ内** にのみ保存されます。

- GitHubには保存されません。このリポジトリにあるのはアプリ本体だけです
- 外部のサーバーにも送信されません。広告も、利用者の追跡もありません
- 他の人が同じURLを開いても、その人には何も表示されません
- 記録は**端末ごと・URLごとに別々**です。複数の端末では同期しません

### 使用容量

「データ」タブの **使用容量** で、いまどれだけ使っているかを確認できます。

- 使用中 ◯◯ KB／上限のめやす 5,120 KB／記録ずみ ◯ラウンド／**あと入る目安 ◯ラウンド**
- 1ラウンドあたりの容量は、2ラウンド以上記録すると**実際のデータから計算**します
- 上限は端末のブラウザの制限でおよそ 5 MB です

実測では、18ホール・スコアのみで約2.9KB、GPS計測を30球含めても約10KBです。
**年30ラウンドまわっても10年以上**入る計算なので、容量を気にする必要はまずありません。

万一、保存に失敗した場合は画面の一番上に赤い帯で警告が出ます。
使用率が80%を超えた時点でも、まだ保存できるうちに注意が出ます。

### 通信量

**起動時以外、いっさい通信しません。** 外部のフォントや画像を読み込まないため、
ラウンド中の通信量はゼロです（GPSは衛星からの受信のみで通信を使いません）。
ホーム画面から起動する場合は端末内のキャッシュから開くため、起動時の通信も発生しません。

### バックアップと復元（重要）

**ラウンドが終わったら、必ずバックアップを取ってください。**

**作成**

1. 「データ」タブ →「**バックアップをコピー**」
2. メモアプリ（iPhone）や Google Keep（Android）に貼り付けて保存

ファイルとして残す場合は「**バックアップ(JSON)**」を押します。
ファイル名は `pocketcoach_backup_YYYY-MM-DD.json`。Androidでは **Downloadフォルダ** に保存されます。

**復元**

- **ファイルから** … 「データの復元」→「ファイルを選択」→ JSONを選ぶ（選んだ瞬間に復元）
- **コピーした文字から** … 入力枠に貼り付けて「読み込む」

復元は「既存データに追加」です。今あるデータは消えません。同じラウンドが両方にある場合は、
新しく更新されたほうが残ります。

## 書き出し（CSV）

「データ」タブの **CSVを書き出す** から、**コースと期間を指定して**書き出せます。

1. **コース** を選ぶ（すべて／記録のあるコースから選択）
2. **期間の開始・終了** を指定（「すべて」「今年」「直近3か月」のワンタップ指定つき）
3. その場で **「対象：3ラウンド／54ホール／飛距離 15球」** と件数が出ます
4. 「スコアCSVを書き出す」または「飛距離CSVを書き出す」

ファイル名に条件が入るので、あとからどの期間のデータか分かります。

```
pocketcoach_scores_sobu-north_20260701-20260930.csv
pocketcoach_distances_sobu-north_20260701-20260930.csv
```

### スコアCSV

```
Round, Date, Course, Nine, Hole, HoleLabel, Par, Score, Putts, FW_Attempt, FW_Hit,
ParOn, BogeyOn, OB, Bunker, Penalty, OneOn, TeeClub, TeeResult, Clubs, Note
```

- `Nine` は27ホールのコースの「東・中・西」。18ホールのコースでは空欄です
- `HoleLabel` は表示用のホール名（`1` または `東1`）
- `Clubs` は計測した実績から打順どおりに生成されます（例 `3W-7U-SW`）
- ラウンド番号（R01・R02…）は日付の古い順に自動で振り直されます

### 飛距離CSV

```
Date, Time, Club, Yards, Meters, Accuracy_m, Course, Hole, ShotNo, Method
```

## 設定（データタブ）

- **目標設定** … 100切り／90切り／80切りから選択
- **クラブセット** … 追加・削除・↑↓での並べ替え。ひな型から一括入れ替えも可能。ここの並び順が入力画面のボタンの並び順になります
- **コース** … 追加・削除ができます。Parをスペース区切りで入力して追加。9ホールを2周する形式は「周回数」に 2 を指定
- **ラウンドの管理** … 日付の変更、ラウンドの削除（そのラウンドの飛距離データも同時に削除）

### 最初から登録されているコース

| コース | 構成 |
|---|---|
| 総武カントリー北コース（既定） | 9ホール×2周／Par 70／2,999Y（Blue） |
| 総武カントリー総武コース | 東・中・西 各9ホール（全27ホール）／Par 108 |
| 総武カントリー印旛コース | 18ホール／Par 72／6,121Y（レギュラー） |
| 標準18ホール | 18ホール／Par 72 |

### コースの削除

各コースの右の「削除」で一覧から消せます。**記録済みのラウンドとスコアはそのまま残ります**
（新しいラウンドで選べなくなるだけです）。コース名の下に「記録◯ラウンド」と出るので、
消していいか判断できます。最後の1コースは削除できません。

初期コースを削除した場合も、開き直したときに勝手に復活することはありません。
戻したいときは「**最初のコースを戻す**」を押してください。

## ホーム画面に追加（アプリとして使う）

このアプリはPWA（インストールできるWebアプリ）です。ホーム画面に追加すると、
**専用アイコンで全画面起動し、圏外でも開けるようになります。**

- **iPhone（Safari）** … 共有ボタン →「ホーム画面に追加」
- **Android（Chrome）** … 右上の ︙ →「ホーム画面に追加」／「アプリをインストール」

ホーム画面から起動したアプリは、iOSの「7日間使わないとデータを削除する」仕組みの
対象外になります。**記録を守るため、必ず追加してください。**

LINEなどのアプリ内ブラウザでは「ホーム画面に追加」が出ません。
必ず Safari／Chrome で開いてから追加してください。

## 更新のしかた

1. 新しい `index_2.html` を用意する
2. このリポジトリで **Add file → Upload files**
3. ファイルをドラッグして **Commit changes**

**同じファイル名なので上書きされ、URLは変わりません。**
画面本体はネットワーク優先で読み込むため、**次に開いたときに自動で新しい版になります。**
保存済みのデータはアプリを更新しても消えません。

iPhoneで反映されない場合は、アプリを終了してから開き直すか、画面を下に引っ張って再読み込みしてください。

## 技術メモ

- アプリ本体は単一のHTMLファイル。外部ライブラリ・外部フォント・画像を一切読み込みません
- PWA対応（manifest + サービスワーカー）。画面本体はネットワーク優先、アイコン類はキャッシュ優先
- 位置情報は Geolocation API（`watchPosition` ＋ `getCurrentPosition`）。2地点間の距離は Haversine 式で算出
- 画面復帰（`visibilitychange` / `pageshow` / `focus`）で測位を張り直し、復帰前の古い測位は使いません
- 計測の開始地点は `localStorage` に退避。アプリが終了しても続きから確定できます
- 大きなボタンは `pointerdown` で反応（clickを待たない）。タップから画面切替まで実測15ms以下
- データは `localStorage` に保存。ブラウザ内で完結します
- グラフはインラインSVGで描画（ライブラリ不使用）
- 画面の更新は変更部分のみを書き換える方式。入力中にスクロール位置が動きません
- iPhone SE（320px）〜Pro Max（428px）×ライト／ダークで横方向のはみ出しがないことを確認済み
